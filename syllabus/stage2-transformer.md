## M4 · 文本表示与分词

### 要掌握的
- 为什么文本比图像难：离散、变长、组合爆炸、语义与形式脱节
- 分词演进：词级（OOV 问题）→ 字符级（序列过长）→ **子词（BPE / WordPiece / SentencePiece）**
- **BPE 算法**：训练过程（统计相邻对频次、迭代合并）与编码过程，两者要分开理解
- 中文分词的特殊问题、多语言 tokenizer 的设计权衡
- 词嵌入：one-hot 的问题 → 分布式表示 → **word2vec**（CBOW / Skip-gram、负采样为什么能加速）→ GloVe
- 嵌入空间的几何性质与局限（静态嵌入无法处理一词多义 → 这直接引出上下文嵌入的动机）
- 评估：内在评估（词类比、相似度）vs 外在评估

### 练习
1. **从零实现 BPE**：训练 + 编码 + 解码，在中文语料上跑通，观察合并出的子词
2. 从零实现 Skip-gram + 负采样，训练词向量，做词类比测试（king - man + woman ≈ ?）
3. 可视化词嵌入空间（t-SNE / UMAP），找出有趣的几何结构
4. 对比：同一份语料上，你的 BPE 和 HuggingFace `tokenizers` 的结果差异在哪、为什么

### 验收标准
- ✅ 能手写 BPE 训练算法的伪代码
- ✅ 能解释：为什么现代 LLM 几乎都用 BPE 系而不是词级分词
- ✅ 能解释：负采样在数学上近似的是什么目标

## M5 · 序列模型

> RNN/LSTM 今天已不是主流，但**必须学**：不理解它们的缺陷，就无法理解 Transformer 每个设计的动机。这个模块的目的是建立"为什么需要注意力"的痛感。

### 要掌握的
- 语言模型的定义与困惑度（Perplexity）—— 会一直用到阶段 3
- n-gram 语言模型与平滑，以及它暴露的稀疏性问题
- **RNN**：参数共享、时间反向传播（BPTT）、梯度消失/爆炸在时间维度上的表现
- **LSTM / GRU**：门控机制如何缓解梯度消失（要能从梯度表达式解释，不是背结构图）
- **seq2seq**：编码器-解码器、固定长度上下文向量的**信息瓶颈**（这就是注意力的直接动机）
- 解码策略：贪心、beam search、采样、top-k、**top-p (nucleus)**、温度

### 练习
1. 从零实现 RNN 的前向 + BPTT（NumPy），再用 PyTorch 复现
2. 实现 LSTM，在字符级语言建模上对比 RNN 的困惑度和长依赖能力
3. 实现完整的解码策略集合，对比同一模型在不同解码策略下的生成质量

### 验收标准
- ✅ 能从梯度表达式解释 LSTM 为什么缓解了梯度消失，以及它**没有**解决什么
- ✅ 能说清 seq2seq 的信息瓶颈具体瓶颈在哪一步
- ✅ 能解释 top-p 相比 top-k 的优势

## M6 · 注意力与 Transformer

### 要掌握的
- 注意力的本质：**软性的、可微的字典查询**（Query / Key / Value 的直觉来源）
- Scaled Dot-Product Attention 的每一处细节：
  - 为什么要除以 √d_k（从方差角度推导，这是经典面试题也是理解题）
  - softmax 在哪个维度上做、为什么
  - 因果掩码（causal mask）的实现与作用
  - padding mask 与 causal mask 的区别
- **Multi-Head Attention**：为什么多头比单头强、参数量分析、实现时的 reshape 技巧
- 位置编码：为什么需要（attention 本身是置换不变的）→ 正弦编码 → 可学习编码 → **RoPE**（现代 LLM 的主流，必须掌握）
- 残差连接与 LayerNorm：**Pre-LN vs Post-LN**（为什么现代模型都改用 Pre-LN）
- FFN 层：为什么是先升维再降维、激活函数选择（ReLU → GELU → SwiGLU）
- 完整架构：Encoder-only / Decoder-only / Encoder-Decoder 三种范式的适用场景
- 复杂度分析：为什么是 O(n²)，这个瓶颈引出了后面所有的长上下文研究

### 练习
1. **纯手写 Scaled Dot-Product Attention**，不用任何现成实现
2. 手写 Multi-Head Attention，用 `einsum` 实现一遍
3. 实现正弦位置编码和 RoPE，可视化对比
4. 消融实验：去掉 √d_k 缩放会怎样？去掉位置编码会怎样？Post-LN 换 Pre-LN 有何差异？**亲手跑出来看，别只是听说**

### 验收标准
- ✅ 白纸上默写完整的 Transformer Block 结构与数据流形状
- ✅ 能从方差角度推导 √d_k 的必要性
- ✅ 能解释为什么 NLP 用 LayerNorm 不用 BatchNorm（M2 的遗留问题，此处闭环）
- ✅ 能读懂《Attention Is All You Need》原文的方法部分

### 资源
- 论文《Attention Is All You Need》（配合《The Illustrated Transformer》图解）
- 李沐《动手学深度学习》第 10–11 章 + 李沐的论文精读视频（中文，极好）
- Karpathy《Let's build GPT from scratch》

## M7 · 从零实现 GPT【阶段 2 大考】

> 这个模块本身就是阶段大考。做完它，你有了第一个真正拿得出手的成果。

### 任务
从空文件开始，实现一个完整的 Decoder-only Transformer 语言模型并训练：

1. 数据管道：语料清洗 → 自己的 BPE tokenizer → 训练/验证集切分
2. 模型：token embedding + 位置编码 + N 层 Transformer Block + LM head，**权重共享**（embedding 与输出层）
3. 训练：AdamW、warmup + cosine 学习率调度、梯度裁剪、混合精度、checkpoint
4. 评估：验证集困惑度曲线、生成样本质量、多种解码策略对比
5. 消融：至少做 3 组消融实验并**写成实验报告**（这是论文实验部分的预演）

### 规模建议
- 笔记本（6GB）：字符级或小词表，~10M 参数，验证代码正确性
- 台式机（5070 Ti 16GB）：BPE 词表，**~50M 参数，这是主训练**

### 验收标准
- ✅ 全程不参考 nanoGPT 等现成实现（写完后可以对照学习）
- ✅ 训练损失正常下降，验证困惑度收敛到合理范围
- ✅ 生成的文本语法基本通顺、局部连贯
- ✅ 交出一份包含消融实验的实验报告（Markdown 即可，但要有图表和分析）
