# 阶段 3 · 现代 LLM 体系

**目标周期：** 10–14 周
**过关标志：** 能读懂任意一篇 LLM 论文/技术报告的方法部分；能在 5070 Ti 上用 QLoRA 微调 7B 模型完成指定任务并给出严谨的量化评估。

> 从这里开始，学习方式发生根本转变：**从"学教材"变成"读论文"**。
> 阶段 1、2 的知识 5 年内不会过时；阶段 3 的内容半年就在变。所以这个阶段真正要学的不是具体技术，而是**跟踪和吸收新技术的能力**。

---

## M8 · 预训练范式与缩放定律

### 要掌握的
- 三大范式对比：**BERT**（双向编码，MLM）/ **GPT**（自回归）/ **T5**（统一 text-to-text）
  - 各自的预训练目标、适用任务、为什么最后是 Decoder-only 赢了
- BERT 系细节：MLM 的 15% 掩码策略、NSP 为什么被后续工作抛弃、RoBERTa 的改进
- **缩放定律**：Kaplan 定律 → **Chinchilla 定律**（参数量与数据量的最优配比），以及它对整个领域的影响
- 预训练数据：来源、去重、质量过滤、数据配比 —— **这是当前最被低估的研究方向之一**
- 涌现能力（emergent abilities）及其争议（是真涌现还是评估指标的产物？这是个活跃的争论，值得读双方论文）
- 上下文学习（In-Context Learning）现象与解释假说

### 练习
1. 精读 BERT、GPT-3、Chinchilla 三篇论文，各写一份结构化笔记（模板见 `03-research/papers/`）
2. 用 HuggingFace 加载 BERT，做一个下游分类任务的微调
3. 亲手验证 In-Context Learning：同一个模型，0-shot / 1-shot / few-shot 在某任务上的表现差异

## M9 · 后训练：从"续写"到"对话"

> 预训练模型只会续写文本。让它变成能用的助手，全靠后训练。这是过去几年变化最快、也最容易找到研究机会的领域。

### 要掌握的
- **SFT（监督微调）**：指令数据的构造、数据质量 >> 数据数量、对话模板（chat template）
- **RLHF 全流程**：偏好数据收集 → 奖励模型训练 → PPO 优化
  - 要能说清 PPO 在这里具体在优化什么、KL 惩罚项的作用是什么
- **DPO**：如何绕过显式奖励模型（要能推导出 DPO 损失怎么从 RLHF 目标导出的，这是理解的关键）
- DPO 之后的演进：IPO、KTO、SimPO、ORPO 等（了解思路即可，重点是理解它们各自在修补 DPO 的什么问题）
- **RLVR / 可验证奖励强化学习**：用规则化奖励训练推理能力（DeepSeek-R1 一路的核心）
- 对齐税（alignment tax）、奖励黑客（reward hacking）、越狱与安全对齐

### 练习
1. **推导 DPO 损失函数**（从 RLHF 的 KL 约束目标出发）—— 这是本模块的核心推导题
2. 用 `trl` 库跑通一次完整的 SFT + DPO 流程（小模型，台式机可行）
3. 对比实验：同一个基座模型，SFT-only vs SFT+DPO，在某个评估集上的差异

## M10 · 高效微调与推理优化

> 这个模块直接决定你作为个人研究者能做多大的实验。**对算力有限的人，这是杠杆最大的一块。**

### 要掌握的
- **PEFT 家族**：Adapter → Prefix/Prompt Tuning → **LoRA**（低秩假设的动机、秩 r 怎么选、作用在哪些权重矩阵上）→ **QLoRA**（4-bit NF4 量化 + 分页优化器）
- 量化：INT8 / INT4、GPTQ / AWQ、量化误差从哪来、什么时候会掉点
- **KV Cache**：为什么能省算力、显存占用怎么算（这个公式要会手算）
- **FlashAttention**：IO 感知的思路（不是近似！是精确注意力的显存优化）、分块与重计算
- 推理加速：投机解码（speculative decoding）、continuous batching、PagedAttention/vLLM
- 长上下文：位置编码外推（NTK-aware、YaRN）、稀疏/线性注意力、状态空间模型（Mamba 一路）

### 练习
1. **手算**：给定模型配置，算出 KV Cache 的显存占用，再实测验证
2. 在 5070 Ti (16GB) 上用 QLoRA 微调一个 7B 模型 —— **这是本阶段的标志性成果**
3. 消融：LoRA 的秩 r 取 4/8/16/64，效果与显存的权衡曲线
4. 部署一次 vLLM，实测吞吐提升

### 验收标准
- ✅ 能独立在 16GB 显存内跑通 7B 模型的微调，并解释每一项显存开销的来源
- ✅ 能手算任意模型配置下的推理显存需求

## M11 · RAG / Agent / 推理模型（前沿）

### 要掌握的
- **RAG**：朴素 RAG 的完整链路 → 各环节的失败模式 → 改进方向（查询重写、重排序、混合检索、GraphRAG）
- 向量检索基础：稠密 vs 稀疏、embedding 模型、ANN 索引
- **Agent**：工具调用、ReAct、规划与反思、多智能体、失败模式与可靠性问题
- **推理模型**：长思维链、测试时计算扩展（test-time scaling）、用 RL 训练推理能力
  - 这是 2025–2026 最热的方向，也是**最容易找到可做研究题目**的地方
- **评估**：这是被严重低估但极其重要的一环 —— 基准污染、LLM-as-judge 的偏差、评估的可复现性问题
- 可解释性（mechanistic interpretability）：探针、激活修补、稀疏自编码器 —— **对算力要求低，非常适合个人研究者**

### 练习
1. 从零搭一个 RAG 系统，然后**系统性地找出它在哪些查询上失败、为什么**（这个"找失败模式"的训练，就是研究的雏形）
2. 复现一个简单的推理时扩展方法（如多次采样 + 投票），量化效果提升
3. 挑一个公开基准，仔细研究它的评估协议，找出至少一个方法论上的问题

## 阶段 3 大考（S3）

1. **论文能力**：给一篇你没读过的近期论文，2 小时内读完，讲清它的问题、方法、实验设计、以及**你认为它的弱点在哪**
2. **实现能力**：QLoRA 微调项目完整交付，含评估报告
3. **判断力**：给出 3 个候选研究方向，分析各自的可行性（对你的算力条件而言）、新颖性、影响力

**通过 S3 = 你已经具备进入阶段 4（研究）的能力。**

## 这个阶段的学习方法转变（重要）

| | 阶段 1、2 | 阶段 3 |
|---|---|---|
| 主要材料 | 教材、课程 | **论文、技术报告、开源代码** |
| 学习方式 | 系统性、线性推进 | 主题式、按需深入 |
| 判断标准 | 会不会做 | **能不能评价好坏** |
| 语言 | 中文为主 | **英文为主** |

从 M8 开始，把每周固定时间分配给：
- **精读 1 篇**论文（写结构化笔记，存 `03-research/papers/`）
- **扫 20 篇**摘要（只判断"值不值得精读"）
- **跑通 1 个**开源项目的核心代码
