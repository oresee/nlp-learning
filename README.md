# NLP 学习系统

从深度学习地基到现代 LLM 体系，最终目标是具备在 NLP 前沿做研究、产出论文的能力。

**运作方式：以和 Claude 的对话为主线，以本仓库资料为辅助，以测评驱动进度调整。**

---

## 🚀 现在就做这三件事

1. **做入门摸底测试** → [`assessments/L0-entry-diagnostic.md`](assessments/L0-entry-diagnostic.md)
   不查资料，90 分钟，答案写进 `assessments/L0-answers.md`，做完在对话里说「L0 做完了」。

2. **装环境** → 照着 [`SETUP.md`](SETUP.md) 第一节装 Miniconda + PyTorch。

3. **配好 Git 同步** → 照着 [`SETUP.md`](SETUP.md) 第三节建私有仓库。**这一步决定你换台式机后记录会不会丢。**

三件事可以并行：等 conda 下载的时候就把测试做了。

## 使用约定

**开始一次学习：** 说「继续学习」。我会读档案，告诉你今天从哪接上。

**结束一次学习：** 说「更新档案」。我把进展、测评、错题写进 `PROGRESS.md`，然后你 `git push`。

**做完测评：** 说「XX 做完了」。我逐题批改，评掌握度，据此调整后续计划。

**卡住了：** 直接问。但先自己想满 15 分钟 —— 卡住的过程本身有价值，太快得到答案会让理解停留在表面。

---

## 几条原则

- **测评不许查资料。** 猜对一道题的代价是我误判你的水平，然后跳过它，最后在后面某个地方崩掉。
- **写"不会"是有效信息，不是失败。** 真实边界比漂亮答卷有用得多。
- **代码练习的核心部分都留空。** 配套有验证脚本（如数值梯度校验），你能自己判断对错，不用等我批改。
- **所有状态写进文件。** 对话会断，档案不断。

## ⚠️ 换设备时必读

`CLAUDE.md` 只在**会话启动时**加载一次，不会自动重读。所以：

**换到另一台机器后，不要恢复旧对话，直接开新会话。**
旧对话的上下文停留在它启动那一刻，看不到你在另一台机器上的进展。

正确流程：

```bash
git pull
```
→ 在项目目录打开 Claude Code → 说「继续学习」

学完之后说「更新档案」，等 Claude 写完，然后：

```bash
git add -A && git commit -m "本次进展" && git push
```

**没 push 就等于没学。** 详见 `CLAUDE.md` 第六节。
