# 数学公式渲染探测

## 为什么需要这个

不同 Claude 客户端的 Markdown 渲染器对 LaTeX 的支持差别很大，而且**失败是静默的** ——
公式不会报错，只会变成一行原始文本或者多出一对括号。更麻烦的是**同一个写法换个位置就挂**，
所以「我上次这么写能行」不是证据。

已经踩过的坑：拿 3 个样本就宣布规则「定死」，下一条消息当场被推翻。
**做探针时要覆盖维度，不要只测几个样例。**

## 已知结论（Claude Code 桌面版，2026-09-18 实测）

| 写法 | 结果 |
|---|---|
| `$$...$$` 独立成行 | ✅ 稳定 |
| `\(...\)` | ⚠️ 有条件，见下 |
| `$...$` | ❌ 不渲染 |
| `\[...\]` | ❌ 不渲染 |
| 反引号包纯文本 | 能显示但是灰底等宽块，夹在中文里很难看，用户已否决 |

`\(...\)` 的两个**独立**条件，必须同时满足：

1. **`\(` 前面是空格或行首。** 中文标点后面要补一个空格。
   - ✅ `其中 \(\beta\) 是衰减系数`　　❌ `其中：\(\beta\) 是衰减系数`
   - 结束符 `\)` 后面接 `，。、` 无影响。
2. **内容不能是光秃秃一个标识符。**
   - ❌ `\(w\)` → 显示成 `(w)`　　❌ `\(w_t\)` → 显示成 `(w_t)`
   - ✅ `\(\mathit{w}\)`、`\(\mathit{w}_t\)`（裸拉丁变量用 `\mathit{}` 包）
   - ✅ `\(\beta\)`、`\(x^2 + 1\)`（有反斜杠命令或运算符就够）

**终端版例外：** `$$` 在终端里也不渲染。用户说在终端，或反馈看到 `\frac` 之类的原文，
就整个改用代码块包纯文本，别用 LaTeX。

## 换客户端后怎么重新探测

不要一次只试一两个然后下结论。**探针要按维度铺开**，一轮拿到全部信息。

把下面这组发给用户，请他逐行报告「渲染成数学符号」还是「显示了原始字符」。
每组单独一行，行首加编号，方便他对着报。

### 探针清单

```
维度 A —— 定界符类型（内容固定用能渲染的 \beta）
A1  $$\beta$$              （独立成行）
A2  \(\beta\)
A3  $\beta$
A4  \[\beta\]

维度 B —— 内容形状（定界符固定 \(...\)，前面都留空格）
B1  \(\beta\)              希腊字母命令
B2  \(w\)                  裸单字母
B3  \(w_t\)                裸字母带下标
B4  \(\mathit{w}\)         \mathit 包裹
B5  \(x^2 + 1\)            无反斜杠但有运算符

维度 C —— 前置字符（内容固定 \(\mathit{g}\)）
C1  行首：             \(\mathit{g}\)
C2  空格前置：  这里是 \(\mathit{g}\)
C3  中文冒号紧挨：如下：\(\mathit{g}\)
C4  中文逗号紧挨：其中，\(\mathit{g}\)
C5  中文标点后补空格：其中， \(\mathit{g}\)
C6  引用块内：> \(\mathit{g}\)
```

### 怎么读结果

- **A 组**告诉你哪种定界符可用。若全挂 → 该客户端不支持 LaTeX，改用代码块包纯文本。
- **B 组**告诉你内容形状有没有门槛。若 B2/B3 挂而 B4 通 → 裸变量要用 `\mathit{}` 包。
- **C 组**告诉你前置字符有没有门槛。若 C3/C4 挂而 C5 通 → 规则是「`\(` 前留空格」。

**注意 C1**：行首也算「前面是空白」。如果只在行首测，会误以为写法没问题 ——
桌面版那次就是这么被骗过一轮的。**每个维度至少要有一个预期失败的对照组**，
全通过的探针说明设计得不够狠，没有区分力。

### 定完规则之后

把结论写进**用户的全局 `~/.claude/CLAUDE.md`**，不要只留在 skill 里。

原因：排版约定是**每次回答都要遵守**的，而 skill 是按需触发的 —— 等它触发就晚了。
全局 CLAUDE.md 每个会话自动加载，才能保证始终生效。
这个 skill 负责的是「怎么重新探测」，不是「平时怎么写」。

如果这个项目有自己的 `CLAUDE.md` 和排版规则，两边都要同步，否则下次会话读到的是旧规则。
