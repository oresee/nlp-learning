**他提出的三个问题（都问在要害上，价值很高）：**

1. **"先算 E[a] 好像算不出来，是出了什么问题吗？"**

2. **"为什么算 Var(w·a)？不是该算 Var(a) 是 Var(z) 的几倍再在 w 里除掉？"**
   → 思路对，用错了量。实测三个分布验证给他看：
   ```
                E[a²]/E[z²]    Var(a)/Var(z)
     正态          0.5001          0.3409
     均匀          0.4999          0.3125
     拉普拉斯      0.4997          0.3748
   ```
   `E[a²]/E[z²]` 恒为 ½（只需对称）；`Var(a)/Var(z)` 随分布而变，写不出通用公式。
   又跑了 50 层×256 单元的模拟给他看后果：
   ```
     Var(w)=1/n     → E[a²] 变为初始的 2.185e-16   湮灭
     Var(w)=2/n     → 1.008                        稳定 ✓
     Var(w)=2.93/n  → 1.811e+08                    爆炸（误用 0.34 的后果）
   ```
   **同一网络只改初始化常数，结果差 24 个数量级。**

3. **"这个 w 是第一个还是第二个？"**「`z'` 是什么意义？」

**① 全零的真实机制（我做了对照实验验证，比他答的"对称性退化"深）：**

```

### 二、第 1 题的核心错误与修复

他写 `w1 ← w1 − 20·lr`。**在第一步数值是对的**（起点 w₁=1，梯度恰好 =20），
但他把梯度当成了常数 —— 于是整道题从"乘法过程"塌成了"减法过程"。

**用的手法（要诀 3，代具体数字）：** 不讲道理，只问两句 ——
1. 「你式子里那个 20 是怎么来的？把 dL/dw₁ 写出来」→ 他写出 `20w₁`
2. 「假设 w₁ 已经变成 0.5，dL/dw₁ 还是 20 吗？」→ 他算出 **10**

**一问就通。** 之后独立完成全部：

```
c1 = 1 − 20·lr        c2 = 1 − 0.2·lr
不发散 ⇒ |c1| < 1 ⇒ 0 < lr < 0.1
lr=0.09 ⇒ c2=0.982 ⇒ n = ln(0.001)/ln(0.982) = 380.3 → 381 步
```

- (b) 他自己写出 `w1 = c1ⁿ` 并解出 lr 范围 —— **完全没给提示**

### 三、条件数（本次的核心概念）

给他看了理论最优 lr 的实算结果，这是全场最有说服力的一击：

```
lr = 0.0990（理论最优）→ 346 步
lr = 0.09  （他用的）  → 381 步
```

> **调 lr 调到天上去也只能从 381 降到 346。这不是调参问题，是算法的结构性缺陷。**

核心句（他接受得很快）：
> **lr 的上限由最陡的方向决定，收敛速度由最平的方向决定。这两个方向不是同一个，于是你被夹在中间。**

`κ = λmax/λmin = 100`，`n ≈ (κ/2)·ln(1/ε)`，实测 κ=1/10/100/1000 → 1/35/346/3454 步。**步数正比于 κ。**

```

### 五、他自己推出了动量
